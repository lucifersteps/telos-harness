# Historical standalone Web UI notices

The standalone Web UI build was imported into early Telos commits and removed in 0.4.11. It is not included in the current plugin or installer. These upstream license texts are retained for readers of Git history.

The inventory covers non-dev, non-optional packages from the original UI lockfile, including tooling dependencies that may not appear in the browser bundle. It does not claim every inventoried dependency was distributed. Each package was fetched from its lockfile URL and checked against its lockfile integrity hash; package code was not executed. Source URLs, exact versions and license texts are recorded alongside this file.
