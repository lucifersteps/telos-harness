# 0.5.2 回归修复验证（2026-11-14）

本记录对应 `codex/fix-052-regressions` 上的修复，不改变已发布的 `v0.5.2` 标签及安装包。[原发布验证](release-0.5.2-validation.md)保留当时的结果。本次尚未实现提醒事项排程模块，也未替换用户运行中的安装。

## 修复范围

- 历史查询：为 DSH 0.2.2 原生历史工具补齐 `agents` 服务，验证桌面压缩后和重启后的搜索、读取及跨会话限制。
- Skill 保留：清理已完成查询时保留成功加载的 Skill 指令和配对的工具调用／结果，包含同批并行调用；验证重启后仍可用。
- 缺少宿主服务：独立检查器在宿主就绪后报告缺少的依赖，CLI 非零退出。保留原启动依赖屏障，避免桌面恢复抢占微信会话。
- 并发确认：修复后到的确认先进入原生 steer 时误撤销预览的问题。较早控制消息尚未分类时暂缓确认；媒体或修改内容仍使旧预览失效，重复确认及发送重试仍只写入一次。新增普通控制消息和带媒体控制消息两种确定性乱序用例。

## 旧测试更新

- 压缩摘要与业务模型回复分别提供夹具，允许宿主提前压缩及额外尝试；仍要求成功压缩、实际历史读取和重启后继续对话。
- 将使用当前包却期待历史故障的桌面会话归属测试，改为当前安装包正常启动和延迟启动两种正向恢复验证。
- 过期草稿测试先明确取消保留草稿，再独立验证新任务对象冲突；异常媒体测试通过 `revise` 续接原草稿。
- 原生请求失败使用 HTTP 401 模拟，避免把可由宿主修复的工具参数错误当作请求失败。
- 没有新增跳过标记，也没有取消未知媒体、跨会话或未确认写入的安全断言。
